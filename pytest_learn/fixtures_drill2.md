# Дрилл по фикстурам №2: зависимость фикстур + conftest.py

Продолжаем с FakeDB (`tests/fake_db.py`). Пути — относительно папки pytest_learn.

---

## Задача 1 — вынести `db` в conftest.py
1. Создай файл `tests/conftest.py`.
2. Перенеси туда фикстуру `db` из `test_fake_db.py` (вместе с нужным
   импортом `from fake_db import FakeDB`).
3. В `test_fake_db.py` УДАЛИ определение фикстуры `db` и её импорт FakeDB.
   Тест `test_insert_dict_to_fake_bd(db)` НЕ трогай — он должен продолжить работать,
   получая `db` уже из conftest (без всякого импорта фикстуры).

Проверка: старый тест по-прежнему зелёный.

---

## Задача 2 — фикстура, зависящая от фикстуры
В `tests/conftest.py` добавь вторую фикстуру `seeded_db`, которая:
- просит в аргументы фикстуру `db`,
- вставляет в неё ДВЕ строки:
  `{"id": 1, "name": "alice"}` и `{"id": 2, "name": "bob"}`,
- отдаёт этот db в тест.

Подумай сам: `return` или `yield` здесь? (подсказка: есть ли у seeded_db
что убирать за собой, или соединение закроет db?)

---

## Задача 3 — тест на seeded_db
В `test_fake_db.py` напиши новый тест, который берёт `seeded_db` и проверяет:
- в нём ровно 2 строки,
- имя первой строки == "alice".

---

## Запуск (из папки pytest_learn)
```bash
.venv/bin/python -m pytest tests/test_fake_db.py -v -s
```

Ожидаемо: оба теста зелёные. С флагом -s посмотри порядок connect/close —
teardown у db должен случиться ПОСЛЕ обоих тестов (по разу на каждый).

Когда решишь — покажи оба файла (conftest.py и test_fake_db.py).
