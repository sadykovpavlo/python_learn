# Дрилл по фикстурам: yield-teardown

Ресурс дан: `tests/fake_db.py` → класс `FakeDB` с методами
`connect()`, `close()`, `insert(row)` и полями `is_open`, `rows`.
Классы писать НЕ надо — только фикстуру и тесты.

Пиши в новом файле `tests/test_fake_db.py`.
(пути относительно папки pytest_learn)

---

## Задача 1 — фикстура с teardown
Напиши фикстуру `db`, которая:
1. создаёт `FakeDB()`,
2. вызывает `.connect()`  (это SETUP, до yield),
3. отдаёт объект в тест через `yield`,
4. после теста вызывает `.close()`  (это TEARDOWN, после yield).

Импорт: `from fake_db import FakeDB`.

---

## Задача 2 — тест, использующий фикстуру
Напиши тест, который берёт фикстуру `db`, вставляет строку
`{"id": 1, "name": "alice"}` и проверяет:
- `db.is_open is True`  (внутри теста соединение живо)
- в `db.rows` лежит ровно эта одна строка

---

## Задача 3 — УВИДЕТЬ жизненный цикл глазами
Запусти с флагом `-s` (он не глушит print):
```bash
# из папки pytest_learn:
.venv/bin/python -m pytest tests/test_fake_db.py -v -s
```
В выводе должен быть порядок:  connect()  →  (тест)  →  close().
Это доказывает, что teardown реально отработал ПОСЛЕ теста.
